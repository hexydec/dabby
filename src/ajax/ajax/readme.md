# $.ajax(url, settings?)

Make an asynchronous HTTP (AJAX) request. The URL may be passed positionally or via the `url` property of the settings object.

For requests with `dataType` of `"script"` or `"jsonp"` (or for any cross-domain request) Dabby injects a `<script>` tag rather than dispatching an `XMLHttpRequest`. All other requests use a real `XMLHttpRequest` so you can abort, inspect headers, or attach progress listeners.

## Signatures

```ts
ajax(url: string, settings?: AjaxSettings): XMLHttpRequest | undefined;
ajax(settings: AjaxSettings): XMLHttpRequest | undefined;
```

## Parameters

- `url` (`string`) — URL to request. May be omitted from the settings object, in which case the current document URL is used.
- `settings` (`AjaxSettings`) — request options:
  - `method` (`"GET" | "POST"`, default `"GET"`) — HTTP method.
  - `data` (`string | FormData | URLSearchParams | object`) — payload. Plain objects are serialised with `$.param`. For `GET` the data is appended to the query string; for `POST` it is sent in the body.
  - `dataType` (`"json" | "jsonp" | "script" | null`) — expected response type. Auto-detected as `"script"` if the URL ends in `.js`.
  - `cache` (`boolean | null`) — when `false` (or `null` for script/jsonp loads) appends a `_=<timestamp>` cache-buster.
  - `async` (`boolean`, default `true`) — passed through to `XMLHttpRequest.open`.
  - `crossDomain` (`boolean`) — force a `<script>` injection rather than XHR.
  - `contentType` (`string | null`) — `Content-Type` header. Defaults to `application/x-www-form-urlencoded; charset=UTF-8` when sending string data.
  - `headers` (`Record<string, string>`) — extra request headers. `X-Requested-With: XMLHttpRequest` is added by default.
  - `xhr` (`() => XMLHttpRequest`) — factory used to create the underlying XHR. Override to inject a mock.
  - `xhrFields` (`Partial<XMLHttpRequest>`) — properties copied onto the XHR before opening (e.g. `withCredentials`).
  - `username` / `password` (`string | null`) — credentials for HTTP basic auth.
  - `context` (`Element | Window | Document`) — value of `this` inside callbacks.
  - `statusCode` (`Record<number, callback>`) — handlers keyed by HTTP status code.
  - `jsonp` (`string`, default `"callback"`) — query parameter name for JSONP.
  - `jsonpCallback` (`string`) — global function name for JSONP. Auto-generated by default.
  - `scriptAttrs` (`Record<string, string>`) — attributes set on the injected `<script>` tag.
  - `success` (`(response, status, xhr) => void`) — fired on a successful response.
  - `error` (`(response, status, xhr) => void`) — fired on a failure (network error, timeout, abort, or HTTP error).
  - `complete` (`(xhr, status) => void`) — fired after `success` or `error`.

## Returns

The underlying `XMLHttpRequest` for asynchronous XHR requests, or `undefined` for `script` / `jsonp` requests (which use a `<script>` tag).

## Examples

```ts
import $ from "dabbyjs";
import "dabbyjs/ajax/ajax/ajax";

// Basic GET returning JSON
$.ajax({
    url: "/api/users",
    dataType: "json",
    success: (users) => {
        console.log(users);
    }
});
```

```ts
// POST a form payload
$.ajax({
    url: "/api/posts",
    method: "POST",
    data: { title: "Hello", body: "World" },
    success: (post) => console.log("Created", post),
    error: (_, status) => console.warn("Failed:", status)
});
```

```ts
// Upload a file using FormData
const form = new FormData();
form.append("file", fileInput.files[0]);

$.ajax({
    url: "/api/uploads",
    method: "POST",
    data: form,
    success: (res) => console.log(res.url)
});
```

```ts
// Abort a previous request
let searchXhr: XMLHttpRequest | undefined;

input.addEventListener("input", () => {
    searchXhr?.abort();
    searchXhr = $.ajax("/api/search", {
        data: { q: input.value },
        success: renderResults
    });
});
```

## Differences to jQuery

Dabby returns the native `XMLHttpRequest`, not a `jqXHR` wrapper, and does not return a `Deferred` — chained `.done()` / `.fail()` / `.always()` are not available. Some settings (e.g. `timeout`, `traditional`, `processData`, `converters`) are not supported.
